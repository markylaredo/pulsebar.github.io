PulseBar

A small, native macOS system monitor that keeps the numbers you care about in the menu bar.

Features Install Customize GitHub

Why PulseBar?

I wanted a system monitor that stays out of the way but still gives you useful information at a glance. PulseBar lives entirely in the menu bar, opens quickly, and uses native macOS APIs—no Dock icon cluttering your screen.

Inspired by Vitals, the excellent system-monitoring extension for GNOME Shell.

What It Shows

📊 CPU & Performance

Live CPU usage, load averages, and per-core utilization

💾 Memory

Activity Monitor-style memory accounting

🌐 Network

Network speed, packet rates, and session totals

💿 Disk

Disk read/write activity and storage usage

🔋 Battery & Thermal

Battery level and macOS thermal state

⚙️ Customizable

Up to five menu-bar statistics, freely reordered in Settings

Real-Time Dashboard

Get comprehensive system statistics at a glance with smooth, live-updating values. Choose between compact or descriptive labels.

  • Smooth menu-bar values with fixed or dynamic width
  • Pin option to keep the dashboard visible
  • System, light, and dark appearances
  • Liquid Glass controls

Make It Yours

Open Settings to reorder statistics, choose which monitors run, change the refresh speed, keep values at fixed positions, or customize the global dashboard shortcut.

The default shortcut is ⌥ ⌘ P. Press it once to open PulseBar and again to close it—even when another app is active.

Installation

Quick Install

Install the latest release with one command:

curl -fsSL https://raw.githubusercontent.com/markylaredo/pulsebar/master/install.sh | bash

The installer verifies the release checksum and code signature, copies PulseBar to /Applications, and opens it.

Build from Source

PulseBar requires macOS 14 or later and Xcode 16 or later.

git clone https://github.com/markylaredo/pulsebar.git
cd pulsebar
open PulseBar.xcodeproj

In Xcode, select the PulseBar scheme, choose your Mac, and press Run.

Uninstall

curl -fsSL https://raw.githubusercontent.com/markylaredo/pulsebar/master/uninstall.sh | bash
