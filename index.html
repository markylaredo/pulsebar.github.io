Native macOS • Lightweight • Menu bar

Your Mac stats,

PulseBar is a small native macOS system monitor that keeps CPU, memory, network, disk, battery, and thermal status right in the menu bar.

Features

Everything important. Nothing noisy.

PulseBar focuses on the system metrics you actually check while staying out of your way.

CPU

CPU & Performance

Live CPU usage, load averages, and per-core utilization.

RAM

Memory

Activity Monitor-style memory accounting with live updates.

NET

Network

Upload/download speed, packet rates, and session totals.

DSK

Disk & Storage

Disk read/write activity plus storage usage at a glance.

BAT

Battery & Thermal

Battery level and the macOS thermal state from public system APIs.

CFG

Fully Configurable

Choose up to five menu-bar stats, reorder them, and tune refresh behavior.

Make it yours

Built to fit your menu bar.

Reorder statistics, choose which monitors run, change refresh speed, keep values at fixed positions, and customize the dashboard shortcut.

  • Compact or descriptive labels
  • Fixed or dynamic menu-bar width
  • System, light, and dark appearance
  • Pin the dashboard when you want it visible
  • Global shortcut: ⌥ ⌘ P
Get PulseBar

Install in one command.

The installer verifies the release checksum and code signature, copies PulseBar to /Applications, and opens it.

Terminal
curl -fsSL https://raw.githubusercontent.com/markylaredo/pulsebar/master/install.sh | bash
