Features

Quick monitoring with deeper tools built in.

PulseBar stays lightweight in the menu bar while giving you detailed system visibility when something deserves a closer look.

CPU

CPU & Performance

Live CPU usage, load averages, per-core utilization, and performance history.

RAM

Memory

Activity Monitor-style memory accounting with live resource history.

PROC

Process Explorer

Sort running processes and inspect per-process resource details.

NET

Network Inspector

Search TCP and UDP connections and trace sockets back to processes.

DSK

Disk & Storage

Disk read/write activity, mounted volumes, capacity, and storage usage.

BAT

Battery & Thermal

Battery level and macOS thermal state using public system APIs.

Make it yours

Built to fit your menu bar.

Reorder statistics, choose which monitors run, change refresh speed, keep values at fixed positions, and customize the dashboard shortcut.

  • Up to five menu-bar statistics
  • Compact or descriptive labels
  • Fixed or dynamic menu-bar width
  • System, light, and dark appearance
  • Pin the dashboard when you want it visible
  • Global shortcut: ⌥ ⌘ P
Get PulseBar

Install in one command.

The installer verifies the release checksum and code signature, copies PulseBar to /Applications, and opens it.

Terminal
curl -fsSL https://raw.githubusercontent.com/markylaredo/pulsebar/master/install.sh | bash
